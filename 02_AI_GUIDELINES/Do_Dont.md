# Do & Don't

The final checklist. Before publishing anything — or if you're an AI, before delivering output — verify against this table.

## Visual

| ✅ Do | ❌ Don't |
|---|---|
| Use only the six brand colors + confetti accents | Introduce any new color, pure black, or pure white |
| Off-white `#F7F5F2` as the default canvas | Stark white or gray backgrounds |
| Instrument Sans 400/600 only | Any second typeface, italics-as-style, ALL-CAPS headlines |
| Use real logo files from `00_ASSETS/logo/` | Redraw, stretch, compress, recolor, or respace the logo |
| Green/dark logo on light bg; light logo on green bg | Green logo on green, or logo on busy backgrounds |
| Keep the safe area around the logo clear | Crowd the logo with text, patterns, or edges |
| One pattern per layout, as background only | Stack patterns, or put body text directly on a pattern |
| One focal point, generous margins | Cluttered layouts, more than one hero element |
| Asymmetric, editorial layouts with visual tension | Centered everything, equal-sized elements, excessive borders |
| Sophisticated, contemporary, minimal, confident | Playful, childish, overly decorative, generic, overly corporate |
| Rounded-corner cards, flat clean shapes | Drop shadows, glows, bevels, 3D text effects, neon gradients |
| Warm candid photos of real people | Stock handshakes, sterile offices, fake smiles |

## Verbal

| ✅ Do | ❌ Don't |
|---|---|
| "Make hiring human again" as the north star | Position Worwyn as an "AI recruiting tool" |
| **Vibe Videos™**, **Mutual Rise™** (exact spelling, ™ first mention) | "vibe video", "mutual-rise", "VibeVideo" |
| Tagline verbatim: "You are more than a resume" | Paraphrases like "You're beyond your CV" |
| Sentence case, short direct sentences | ALL CAPS, exclamation stacking!!!, hedging ("we believe that perhaps…") |
| "You / people / candidates / employers" | "Users / talent pool / human capital / assets" |
| At most one warm emoji when it fits | Emoji walls 🎉🚀🔥💯 |
| Plain verbs: meet, see, feel, connect, rise | Jargon: leverage, synergy, seamless, empower, disrupt, game-changer |
| Critique broken hiring *processes* | Mock recruiters or HR people |
| Ask a human when facts are missing | Invent statistics, features, pricing, or testimonials |

## The two-question gate

Before shipping, ask:

1. **Does it look like folded green paper on a warm desk?** (calm, tactile, green-dominant, one focal point)
2. **Does it make hiring feel more human?** (a real person would feel seen, not processed)

Two yeses → ship it. Anything else → revise.
