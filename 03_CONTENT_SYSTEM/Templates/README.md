# Templates

Ready-made PNG templates built from the real brand assets (extracted logo marks, patterns, Instrument Sans, official palette).

| File | For | Size |
|---|---|---|
| `ig-feed-announcement-1080x1350.png` | Instagram statement/announcement posts | 1080×1350 |
| `ig-quote-1080x1080.png` | Instagram quotes & Mutual Rise™ stories | 1080×1080 |
| `ig-carousel-cover-1080x1350.png` | Instagram tip-carousel covers | 1080×1350 |
| `ig-story-1080x1920.png` | Instagram/Facebook stories, Reel covers | 1080×1920 |
| `linkedin-post-1200x1200.png` | LinkedIn feed images | 1200×1200 |
| `presentation-title-1920x1080.png` | Deck title slides | 1920×1080 |
| `presentation-content-1920x1080.png` | Deck content slides | 1920×1080 |

## How to use

1. Open the PNG in Canva, Figma, Photoshop — any editor (or set it as a slide background).
2. Replace the placeholder text with your copy, keeping position, size, and color. Font: **Instrument Sans** (Semibold 600 headlines, Regular 400 body) — [get it free](https://fonts.google.com/specimen/Instrument+Sans).
3. Keep everything else as is: margins, logo position, colors.
4. Check the result against [`../../02_AI_GUIDELINES/Do_Dont.md`](../../02_AI_GUIDELINES/Do_Dont.md).

To build new layouts from scratch, use the assets in [`../../00_ASSETS/`](../../00_ASSETS/README.md) and follow [`../../02_AI_GUIDELINES/Visual_Language.md`](../../02_AI_GUIDELINES/Visual_Language.md).
