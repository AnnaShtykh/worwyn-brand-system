# References

Example designs for social media posts.

**Important: these are references, not templates.** They show one good way the brand can look in a feed — the level of quality, the mood, the use of color and type. Future posts do **not** need to copy these layouts. Treat them as inspiration and a quality bar, then design each post from the actual rules:

- [`../Composition_Checklist.md`](../Composition_Checklist.md) — asymmetric, editorial, minimal
- [`../../02_AI_GUIDELINES/Visual_Language.md`](../../02_AI_GUIDELINES/Visual_Language.md) — composition, patterns, product UI style
- [`../../00_ASSETS/`](../../00_ASSETS/README.md) — real logo marks, patterns, colors

If a reference and a rule ever disagree, **the rules win**.
