# Brand Assets

Real brand asset files extracted from the official Worwyn brand book. Use these instead of recreating anything by hand.

## `logo/`

| File | What it is | Use on |
|---|---|---|
| `worwyn-mark-green.png` | Origami "W" mark, signature green, **transparent background** | Light backgrounds (off-white, beige, light green tint) |
| `worwyn-mark-silver.png` | Origami "W" mark, silver/paper white, **transparent background** | Dark or rich green backgrounds |
| `worwyn-mark-dark.png` | Origami "W" mark, deep black/dark green, **transparent background** | Light backgrounds when a quieter look is needed |
| `worwyn-logo-primary-light-bg.png` | Full lockup (mark + gradient wordmark) on white | Primary logo for light surfaces |
| `worwyn-logo-green-on-beige.png` | Primary lockup on warm beige | Reference for beige surfaces |
| `worwyn-logo-light-on-green.png` | Light lockup on dark green | Reference / crops for green surfaces |
| `worwyn-logo-dark-on-beige.png` | Dark lockup on warm beige | Reference for muted light surfaces |

**Rules:** never stretch, compress, recolor, rotate, or change the spacing between mark and wordmark. Keep the safe area (the height of the "W" counter) clear around the logo. See [`../01_BRAND_FOUNDATION/Logo.md`](../01_BRAND_FOUNDATION/Logo.md).

## `patterns/`

| File | What it is | Use for |
|---|---|---|
| `pattern-w-zigzag-green.png` | Tonal W zigzag on primary green | Bold brand surfaces, story backgrounds, covers |
| `pattern-confetti-offwhite.png` | Green/amber/mint confetti on off-white | Celebration moments — matches, hires, milestones |
| `pattern-w-outline-green.png` | Thin-line origami W outlines on dark green | Premium, quiet surfaces — closing slides, stationery |

Patterns are decorative backgrounds. Don't place body text directly on the zigzag or outline patterns without a solid color block behind it.

## `colors/`

Flat PNG swatches of every brand color, named `<name>-<hex>.png`, for quick color-picking in any tool.
Full palette, RGB values and usage rules: [`../01_BRAND_FOUNDATION/Colors.md`](../01_BRAND_FOUNDATION/Colors.md).
